# Экран фитнес-трекера на Swift

`DashboardView.swift` содержит экран фитнес-трекера для iOS. На нём показаны дневная цель, шаги, калории, дистанция и примеры тренировок. Кнопка открывает список типов тренировок.

## Использование в Xcode

Добавьте файл в iOS-приложение на SwiftUI и отобразите `DashboardView()` из точки входа приложения. Для запроса разрешения HealthKit добавьте соответствующую возможность и описание доступа к данным в настройках iOS-цели.

Экран запрашивает доступ к HealthKit. Карточки используют демонстрационные значения из `loadHealthData()`, а история тренировок задана в разметке.
